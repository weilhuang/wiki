# 学习路线

路线只安排阅读和任务，不拥有正文。你可以从领域目录直接进入知识点，也可以按这里的阶段推进；相邻两篇不自动构成强先修。

## Spring 服务原理

解释对象、请求、事务和连接各自的完成边界，再评审一个本地订单接口。

进入前：Java 调用与异常；HTTP 请求响应；SQL 提交与回滚。

[查看路线与阶段任务](/paths/spring-service-principles.html)

## Go 可靠服务

为请求、工作、下游调用和进程退出定义所有者、等待上限与资源收尾。

进入前：Go 函数、error 与 defer；channel 与 goroutine；HTTP 请求响应。

[查看路线与阶段任务](/paths/go-reliable-services.html)

## 数据与消息一致性

从业务不变量走到未知结果、事件交接、缓存和联合恢复，解释每个局部承诺。

进入前：SQL 与唯一约束；事务提交和回滚；两个会话的交错执行。

[查看路线与阶段任务](/paths/data-message-consistency.html)

## 身份与多租户

从可信身份进入一次订单操作，比较撤销时效，并为租户、对象、动作与提交时刻建立默认拒绝规则。

进入前：能区分 HTTP 请求的调用方与服务端；能读条件判断和一条订单记录。

[查看路线与阶段任务](/paths/identity-tenancy.html)

## Java 核心机制

从键与对象状态进入跨线程可见性，再跟踪任务接纳、结果所有权与运行时证据。

进入前：能阅读 Java 引用、字段、方法与异常；知道线程可以共享对象；每篇补足具体同步概念。

[查看路线与阶段任务](/paths/java-core.html)

## 服务观测与发布可靠性

先定义用户事件与服务目标，再用局部证据定位原因，最后解释发布时的路由、排空和资源释放。

进入前：了解一次请求的输入、结果与超时；能区分新工作接纳和已有工作完成；正文补充分布与探针概念。

[查看路线与阶段任务](/paths/service-reliability.html)

## 系统设计与演进

提交可反驳、可停止且写清失败与恢复责任的架构决定。

进入前：能描述业务不变量与本地事务；每篇补足最小背景，跨域主题按问题选读。

[查看路线与阶段任务](/paths/architecture-evolution.html)

## 路线草案

- **性能诊断**：用负载和证据区分排队、连接、SQL 与运行时瓶颈。已有服务目标与 Java/Go 有限诊断；代表性负载、容量模型和端到端性能实验仍待补齐。

草案没有“开始完整课程”入口。已经知道某阶段结论时，可先完成它的任务；能给出条件和反例，再跳过对应阅读。
