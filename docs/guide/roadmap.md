# 后续知识范围

当前阅读入口是 [Spring 服务边界](/learn/spring-service-boundaries/)、[Go 服务生命周期](/learn/go-service-lifecycle/)和[数据一致性](/learn/data-consistency/)三条路径。它们解决服务交接与持久状态的一部分问题，不等于完整的后端百科。

下面是后续可以继续展开的主题。它们尚未形成独立课程，因此没有空页面或尚不可运行的章节入口，也没有承诺完成日期。

| 方向 | 需要承接的基础 | 形成独立路径前需要的实验产物 |
| --- | --- | --- |
| Java 与 Go 运行时 | 资源所有权、阻塞和并发 | 内存/调度假设、可重复 profile、错误解释的反例 |
| 存储性能与恢复 | 不变量、隔离和索引 | 执行计划、负载分布、备份恢复与恢复点验证 |
| 真实消息系统 | outbox、去重与重放 | 固定 broker 环境中的确认、offset、顺序和重平衡证据 |
| 分布式任务与复制 | 未知结果、幂等和持久恢复 | 节点故障/网络分区模型、恢复协议和保证退化说明 |
| 云原生发布 | 进程停机、连接与预算 | 真实集群中的摘流、滚动发布、配置和容量验证 |
| 可观测性与性能 | 时间线、等待和业务状态 | 可追踪的 SLO、指标/日志/追踪关联、性能诊断前后对照 |
| 身份与安全 | HTTP 信任边界、数据分类 | 认证/授权模型、威胁分析、失败默认拒绝与密钥轮换演练 |
| 架构演进与工程方法 | ADR、失败矩阵和恢复手册 | 迁移约束、回滚条件、兼容策略与成本比较 |

后续内容仍按同一标准组织：有可复现问题、机制与失败图、完整实验、能识别错误实现的断言，以及可独立完成的综合评审。主题多寡不替代证据。
