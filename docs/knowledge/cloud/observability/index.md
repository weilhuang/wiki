# 观测与服务目标

[知识目录](/knowledge/) / [云原生与可靠性](/knowledge/cloud/)

选择能回答问题的指标、日志和追踪，控制基数与隐私。

## 阅读定位

知道请求会失败、超时或重试；分子分母和百分位在正文补充。

观测边界先决定事件身份，再求好事件比例与分布。RED看服务症状，USE查资源等待；采样追踪与总体计数承担不同职责。

## 怎样选择阅读入口

先定义一个请求路径的分母与好事件，再复算比例和百分位，最后讨论预算、低流量、采样及标签成本。

常见混淆：平均实例百分位、把零流量填成100%、把采样错误比例当总体、事后从分母删除发布失败。

**小目标**：改变流量分配或采样规则，说明哪一个统计量变了，并用固定样本拒绝错误计算。
