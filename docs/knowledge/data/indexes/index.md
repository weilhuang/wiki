# 索引与查询

[知识目录](/knowledge/) / [数据与存储](/knowledge/data/)

从访问路径解释筛选、排序、回表和分页代价。

## 阅读定位

能阅读 SELECT、WHERE 与 ORDER BY；主文用固定订单表补充复合有序键、二级索引与主键回查。

索引定位候选范围，后续仍可能过滤、取出非索引列并排序。优化器选择路径，执行器产生实际行；估计、执行次数与业务行集需要分开检查。

## 怎样选择阅读入口

先对同一查询分别看有无提示的计划，再改变投影列、等值与范围条件。能解释每个阶段后，再把实际扫描和等待放回事务与连接预算。

常见混淆：范围列之后的条件仍可能参与过滤，不能概括成完全失效；缺左前缀也不保证绝不使用索引；FORCE INDEX 的观察不能冒认优化器自然选择。

**小目标**：保持返回四行不变，比较覆盖与非覆盖查询的路径；再构造漏租户条件的错误查询，用完整行集而非仅退出码识别它。
