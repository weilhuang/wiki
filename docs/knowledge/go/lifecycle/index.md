# 进程生命周期

[知识目录](/knowledge/) / [Go 工程](/knowledge/go/)

先停止接纳，再等待已有工作，最后释放依赖。

## 阅读定位

请求处理合同、取消与 join、工作所有权。

进程依次停止接纳、等待已有工作、取消超期任务、释放共享依赖。HTTP 服务器只拥有其中一部分工作，后台池和特殊连接需要自己的合同。

## 怎样选择阅读入口

先画所有者，再读停机状态机和预算来源，最后用真实 main 子进程检查退出码与依赖关闭；平台摘流是下一层问题。

常见混淆：Serve 返回不等于在途请求结束；Shutdown 返回不代表任意后台任务都已退出；进程内任务没有崩溃恢复保证。

**小目标**：分别安排正常排空、超期和启动失败，说明哪些工作被等待、何时关闭依赖、退出码保留什么事实。
