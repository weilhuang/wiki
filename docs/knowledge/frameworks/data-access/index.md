# 数据访问与连接

[知识目录](/knowledge/) / [框架与服务通信](/knowledge/frameworks/)

连接占用、等待和事务范围共同决定服务资源成本。

## 阅读定位

线程、连接、事务的区别；先理解事务怎样持有和归还连接。

池拥有物理连接，调用借用连接，事务扩大持有范围。等待借用、持有时等待外部资源、数据库内部等待会产生相似延迟，但对应不同修复。

## 怎样选择阅读入口

先读连接持有与数量，再比较短事务和超时；出现现象时转到连接等待排障，目标数据库锁与隔离另读数据领域。

常见混淆：active 不等于 SQL 正在执行；挂起外层事务不等于归还连接；多配超时不等于建立统一请求预算。

**小目标：**画出两个请求与一条连接的所有权，说明延长等待和缩小持有范围各改变哪一段。
