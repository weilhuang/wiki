# 授权

[知识目录](/knowledge/) / [身份与安全](/knowledge/security/)

权限判定需要资源、动作和上下文。

## 阅读定位

身份已经由可信边界验证；能够描述资源归属、租户、动作和请求中的不可信字段。

授权判断把主体与某个资源、动作和上下文联系起来。策略决定能否访问，执行点必须让实际查询或修改受同一边界约束；对象归属与委托范围变化后，旧判断可能不再适用。

## 怎样选择阅读入口

先列主体、租户、对象、动作四个维度，再从默认拒绝开始增加允许条件。将同一判断用于读取与修改，并用跨用户、跨租户、对象归属变化和服务代理检验边界。

常见混淆：只检查角色会遗漏对象归属；请求里的 tenant_id 不是可信授权依据；隐藏按钮也不能限制直接调用接口。

**小目标**：为订单读取和修改各设计一组允许与拒绝矩阵，让越租户和委托扩权在真正执行业务之前被拒绝。
