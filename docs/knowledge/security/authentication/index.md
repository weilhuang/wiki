# 认证

[知识目录](/knowledge/) / [身份与安全](/knowledge/security/)

身份建立、会话延续和撤销需要完整生命周期。

## 阅读定位

知道 HTTP 请求可以携带 cookie 或 header，能区分服务端状态与客户端提供的字节。

身份建立、凭据验证、会话延续和撤销是不同阶段。一个声明只有经过适用的验证并处在明确的信任边界内，才可以作为后续授权的输入；凭据仍然有效也不代表每个对象都可以访问。

## 怎样选择阅读入口

先追踪一次会话怎样建立、使用和结束，再比较服务端会话与自包含令牌把状态放在哪里。随后改变受众、期限或撤销状态，检查哪一方何时有足够信息拒绝请求。

常见混淆：能解码令牌不等于验证过令牌；用户退出界面不等于所有已签发凭据立即失效；认证成功不是对象级授权。

**小目标**：给一份仍未过期但已撤销的凭据画验证时间线，说明两种会话方案各在哪里获知撤销、允许多长不可见窗口。
