# 可靠交互

[知识目录](/knowledge/) / [消息与分布式](/knowledge/distributed/)

未知结果需要稳定身份和查询入口，重试需要预算与责任。

## 阅读定位

本地事务、业务身份与唯一约束；理解响应丢失不能裁决提交结果。

操作身份把多次尝试关联到一次裁决，请求摘要检查是否仍是同一操作，持久结果支撑查询与复用，保留期决定保证何时结束。

## 怎样选择阅读入口

先区分未知观察与持久状态，再看唯一键裁决和提交前后窗口；外部副作用需要在各自责任边界继续设计。

常见混淆：带一个 Idempotency-Key header 不会自动让业务幂等；副本未命中不是尚未执行的证明。

**小目标：**安排同键同参、同键异参、提交后丢响应与过期清理，分别写出允许的下一步。
