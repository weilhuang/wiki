# 协调与共识

[知识目录](/knowledge/) / [消息与分布式](/knowledge/distributed/)

把故障模型、时钟假设和所有权有效期写清。

## 阅读定位

本地操作身份、主体/资源授权，能区分暂停和取消

租约让协调器安排接管；接收端以可信作用域的单调水位拒绝已被新代次取代的请求

## 怎样选择阅读入口

先跟踪暂停恢复的旧持有者，再检查token来源与资源端原子提交，最后分析同token重放和恢复重置

常见混淆：租约到期不撤回外部在途写；更大的裸数字不等于授权；fencing也不消除同代次业务重放

**小目标**：让新代次先提交，再安排旧代次写入；同时断言返回、业务值、水位和副作用没有被改变
