# 并发基础

[知识目录](/knowledge/) / [Java 平台](/knowledge/java/)

把原子性、可见性、顺序和等待分开，才有条件判断线程安全。

## 阅读定位

Java 引用、字段与方法调用；知道两个线程可以读写同一个对象，不要求先读锁实现。

读写动作之间的 happens-before 关系限制允许的观察；原子性、可见性与对象发布分别回答不同问题。线程开始、同步操作、任务提交与取回结果提供具体边界，墙上时钟的先后不替代这些关系。

## 怎样选择阅读入口

先从 value 与 ready 两个字段推导读者能知道什么，再比较 volatile 与复合自增，最后检查对象状态怎样安全发布。需要组织多个任务时进入执行器，锁与并发容器是后续扩展。

常见混淆：一次测试总读到正确值不是所有执行都正确的证明；volatile 不会把读改写变成一个动作；final 也不保护对象发布后的任意修改。

**小目标**：画出写入、发布与读取之间的边，删除一条边后说明哪些结论不再成立，再用可控交错反驳“volatile 自增就是原子”的说法。
