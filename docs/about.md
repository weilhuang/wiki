# 关于这个知识站

这里把后端工程知识整理成可顺序学习、也可按问题查阅的路径。每章承担一个明确的问题域，相关机制通过章节链接连接，避免同一段基础知识在不同主题反复出现。

当前重点是服务边界、工作与资源生命周期，以及订单场景中的数据一致性。[知识地图](/guide/knowledge-map)说明已有内容与先修关系；[后续范围](/guide/roadmap)单独列出尚未展开的领域。

## 内容与证据原则

- 先写前提和业务/资源不变量，再解释调用链与状态变化
- 实现敏感的结论绑定具体版本，关键事实指向官方文档或固定源码
- 提供完整源码与可重复入口；测试需要能够识别至少一种错误实现
- 将静态检查、单元测试、真实服务实验与生产验证分别说明，不虚构运行结果或个人经历
- 给出替代方案、适用条件和剩余风险；示例不是无需调整即可上线的模板

发布日期记录首次公开，修订日期记录内容更新，都不改变学习顺序。实验的版本和证据只对其绑定源码有效；修改实现、依赖或运行环境后，应重新验证受影响的结论。

## 勘误与复现

源码位于 <a :href="site.repoUrl">GitHub 仓库</a>。提出问题时，请带上章节链接、实验包版本、运行命令、实际与预期结果，并尽量提供最短复现。先移除日志中的凭据、个人信息和业务数据。

页面使用 VitePress 默认主题，代码由 Code Hike 的构建期适配处理，图表由本地 Mermaid 渲染。本地搜索不会把查询发送给第三方；站点没有第三方统计或评论服务。
