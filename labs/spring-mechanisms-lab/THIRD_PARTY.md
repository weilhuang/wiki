# Third-party material

Spring Framework source snapshots are unmodified files from spring-projects/spring-framework tag v6.2.19. Spring Boot snapshots are unmodified files from spring-projects/spring-boot tag v3.5.16. Exact official URLs and SHA-256 values are in source-lock.json. Their original headers and Apache License 2.0 notices remain intact.

Dependency JARs are not redistributed. Their immutable coordinates and content hashes are in dependencies.lock.json. Embedded license and notice files from Spring Framework, Spring Boot and Micrometer are copied without modification into licenses/. The Spring Framework license file also carries bundled third-party notices.

AssertJ Core 3.27.7 declares Apache-2.0 in its published POM and does not have an embedded license/notice entry in the inspected JAR. The unmodified POM is preserved as licenses/assertj-core-3.27.7.pom and the Apache 2.0 license text is LICENSE. This does not imply that AssertJ's source code is included.

The example and verification code is offered under Apache License 2.0. Source review records are scoped to the methods discussed, not a complete audit of these projects.
